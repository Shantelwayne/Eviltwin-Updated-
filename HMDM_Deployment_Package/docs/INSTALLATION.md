# HMDM Installation Instructions

## System Requirements

- Windows 10 or later
- 4GB RAM minimum (8GB recommended)
- 10GB free disk space
- Administrator privileges
- Internet connection (for downloads)

## Quick Start (Docker)

1. Right-click `installers\HMDM_Docker_Installer.bat`
2. Select "Run as administrator"
3. Wait for installation to complete
4. Open http://localhost:8080
5. Login with admin/admin

## Troubleshooting

- **Port 8080 in use:** Stop other web servers or change HMDM port
- **Docker issues:** Restart Docker Desktop and try again
- **Database errors:** Check PostgreSQL service is running
- **White page:** Wait 2-3 minutes for full initialization
