🚀 Getting Started

📋 Prerequisites

  • ✅ Docker Desktop installed
  • ✅ aPuppet server files
  • ✅ Android device with aPuppet app
  • ✅ Network connectivity

⚡ Quick Launch

  • 1. Run START_APUPPET_SERVER.bat
  • 2. Open http://localhost/web-admin/
  • 3. Enter session credentials
  • 4. Start remote control!
